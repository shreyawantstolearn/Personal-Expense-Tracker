# Personal Expense Tracker

A Python-based expense tracking application that helps users manage their daily spending through a simple menu-driven interface.

## Features

- **Add Expenses:** Record expenses with a name, amount, and category.
- **Search Expenses:** Find existing expenses.
- **Update and Delete:** Modify or remove expense records.
- **Category Management:** Organise expenses by categories and view category-wise spending.
- **Spending Summary:** Calculate total spending and category-wise totals.
- **Highest Expense:** Identify the expense with the highest amount.
- **Input Validation:** Handle invalid amounts and menu choices.
- **Duplicate Prevention:** Prevent duplicate expense names within the same category.
- **Data Persistence:** Save and load expense records using JSON files.
- **Separate User Files:** Store expenses in separate files based on the entered username.

## Technologies Used

- Python
- Dictionaries and Nested Dictionaries
- Loops and Conditional Statements
- Exception Handling
- JSON File Handling

## How to Run

1. Install Python 3 if it is not already installed.
2. Download or clone this repository.
3. Open a terminal in the project folder.
4. Run the program:
      expense_tracker.py
   

Replace `expense_tracker.py` with the actual name of your Python file if it differs.
